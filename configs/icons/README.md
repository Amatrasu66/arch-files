# Icon Theme: Papirus-Dark

The desktop icon theme is set to `Papirus-Dark` across:
- `~/.config/gtk-3.0/settings.ini` (`gtk-icon-theme-name=Papirus-Dark`)
- `~/.config/gtk-4.0/settings.ini` (`gtk-icon-theme-name=Papirus-Dark`)
- `~/.config/xsettingsd/xsettingsd.conf` (`Net/IconThemeName "Papirus-Dark"`)
- `~/.config/fuzzel/fuzzel.ini` (`icon-theme=Papirus-Dark`)
