# Security Policy

## Reporting Security Vulnerabilities
If you discover a security vulnerability or accidental exposure of sensitive data in this repository, please do not open a public issue. Contact the repository owner directly or submit a private security advisory on GitHub.

## Sanitization Policy
All configuration files in this repository have been strictly sanitized:
- User names and emails are templated.
- Hardware-specific partition UUIDs are replaced with placeholders.
- Wi-Fi passwords and personal tokens are excluded.
