# Default Desktop Profile

The **Default** profile installs the full reference desktop environment:
- Niri scrollable-tiling Wayland compositor
- Modesty Dynamic Island shell (via QuickShell)
- Kitty terminal with Catppuccin Mocha glassmorphism
- Fuzzel application launcher and dmenu utilities
- PipeWire audio stack & WirePlumber
- Swaybg wallpaper daemon
- Swaylock and inactivity power management
- Full application suite (browsers, Thunar file manager, media tools)
